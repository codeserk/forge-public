# @codeserk/forge-api-internal-generated

Auto-generated TypeScript client for the Forge internal API. Do not edit by hand.

Use [`@codeserk/forge-api-internal`](../api-internal/README.md) for a friendly wrapper that handles PAT auth and HMAC signing.

## Regenerate

Against a running api-internal server:

```sh
npm run generate:local
```

Against a swagger.json file:

```sh
npm run generate:file path/to/swagger.json
```
